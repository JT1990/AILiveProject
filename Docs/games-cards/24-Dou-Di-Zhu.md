# 斗地主 / Dou Di Zhu (Fight the Landlord)

- **来源**: 纸牌
- **出处**: 传统游戏（中国民间纸牌游戏）
- **玩家人数**: 3 人
- **游戏时长**: 约 20-40 分钟
- **核心机制**: 不对称阵营对抗（1v2），通过出牌组合先出完手牌者获胜
- **规则摘要**: 使用一副54张牌（含大小王），每人发17张，剩余3张为底牌。通过叫分（1-3分）竞价确定"地主"，地主获得3张底牌（共20张），两位"农民"各持17张牌并结为同盟。地主先出牌。出牌牌型包括：单张、对子、三带一/二、顺子（至少5张连续）、连对、飞机（连续三条带附带牌）、炸弹（四张相同）、火箭（大小王）等。后出者必须以相同牌型且更大的牌压过上家，或选择不出。炸弹和火箭可以压任何牌型。任一方（地主或农民中任一人）先出完所有手牌即该方获胜。
- **关键策略**: 地主方需要充分利用多出的3张底牌和先手优势快速出牌；农民方需要默契配合，一人主攻出牌一人辅助拆牌压制地主。记牌（特别是追踪炸弹和关键大牌的位置）是高水平对局的基础。叫分决策需要评估手牌质量——牌型连贯且有炸弹时适合做地主，否则应放弃叫牌。
- **AI适配评估**:
  - 可行性: 高
  - 所需能力: [推理/合作/记忆/计算]
  - 改造建议: 已有成熟的AI研究基础（如DouZero等算法）。纯文本适配方便：手牌和出牌均可用文本列表表示。农民间的合作是核心看点——建议禁止农民直接沟通，迫使AI通过出牌行为传递信息（如主动出小牌暗示队友手牌强）。系统播报每手出牌，AI需维护"记牌器"追踪剩余牌的分布。叫分环节可增加AI的风险评估展示。
