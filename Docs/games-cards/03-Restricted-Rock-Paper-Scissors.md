# 限定ジャンケン (Restricted Rock Paper Scissors / 限定猜拳)

- **所属作品**：漫画《賭博黙示録カイジ》第一部／动画《逆境無頼カイジ Ultimate Survivor》第 1-6 话／电影《カイジ 人生逆転ゲーム》(2009)。Espoir（希望号）邮轮之夜。
- **游戏阶段**：主要赌局（开篇第一场大赌局）
- **玩家人数**：数百名背负巨债的"债务人"共同参与；每一局为两人面对面对战，但可自由在大厅内寻找对手。
- **核心机制**：博弈论 + 市场流动性博弈 + 不完全信息手牌管理；本质是"博弈树剪枝 + 信息套利 + 联盟破坏"的综合体。
- **规则摘要**：
  - **初始分发**：每位参赛者获得 12 张手牌（石头 ×4 / 剪刀 ×4 / 布 ×4），以及 3 颗星星（塑料质地，挂在胸前）。
  - **对局流程**：两人相向，同时各出 1 张牌，胜者从败者处取走 1 颗星星；平局则双方不损星星，但牌都被回收（这是最关键的设计）。
  - **时限**：总计 4 小时；会场有显示倒计时大屏。
  - **胜利条件**：到 4 小时结束时，必须同时满足①星星 ≥ 3 颗 ②手牌全部出完。
  - **失败后果**：星星 < 3 或手牌还有剩余，债务继续并被送往"地下強制労働施設"（地下劳动所）做苦工偿债（每日 ¥10,000，复利）。
  - **星星交易**：场内设有交易所；星星可现金买卖，价格由供需决定（从 1 颗 ¥1,000,000 一路飙升至 ¥20,000,000+）。每 10 分钟给一次结算窗口。
  - **借贷系统**：场上可向黑幕公司"帝愛（Teiai）"借现金购买星星，利率 **1.5% 每 10 分钟**（相当于 4 小时复利 140%）——这是逼迫玩家尽快结束游戏的设计。
  - **"解放"机制**：每付出 3 颗星星可以"买下"另一房间一个人的自由（把对方拉进你的阵营/或为慈善）。
  - **著名战术**：
    - **同盟合作**：多人形成"互出同款手牌 → 全体平局 → 快速消耗手牌但不损星"的联盟（最后内部互相送星保住 3 颗星的人）。
    - **偷牌作弊**：反派古畑、福本等人偷换他人手牌制造信息不对称。
    - **"石头只剩一张"的心理战**：看穿对手手牌分布后进行叫牌（类似扑克的 range 推断）。
- **胜负条件**：4 小时后手牌归零 + 星星 ≥ 3；赌注为自由与数千万日元的债务。
- **信息结构**：不完全信息（对方剩余手牌组成未知，但可通过推断与公开信息缩小范围）。
- **互动模式**：纯对抗为主，但允许短暂联盟—背叛混合；晚期会出现"弃卒保车"的团体博弈。
- **所需能力标签**：概率计算、记忆力（己方/对方已出牌）、心理博弈、谈判、信任评估、风险管理（借贷成本）。
- **AI 适配笔记**：
  - 极易移植，信息空间小（每人 ≤12 张 3 类牌 + 3 星）。
  - AI 的核心挑战在于"联盟—背叛"的信号博弈：需要评估长期合作价值 vs 短期背叛收益。
  - 可以简化为纯 3×3 矩阵 RPS + 星星经济模型；或引入"借贷利率"作为全局压力变量。
  - 值得做多 Agent 的压力测试舞台（10+ 参与者 + 市场交易）。
