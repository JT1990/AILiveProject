# 友情の檻ゲーム (Yuujou no Ori Game / 友情牢笼游戏 / 友情之牢)

- **所属作品**：漫画第9-10卷
- **游戏阶段**：大人のトモダチゲーム 第1回
- **玩家人数**：12人（友一、誠、四宫圭、水谷恵子、種田龍星、黒木、不動南、山下健二、宮部沙織、後呂田涉、川上実、田上源丈）
- **核心机制**：集体劳动 vs 个人逃脱、投票放逐、囚徒困境升级版
- **规则摘要**：
  - 场景设定为监狱。12名参赛者被关押，有两种通关方式：
    - **方式A——服刑**：全员在监狱中度过等同"20年刑期"的时间（游戏内时间压缩）。
    - **方式B——合作建造**：全员合力完成**12万个多米诺骨牌**的排列，全部站立即通关。
  - **逃脱机制**：存在隐藏的逃脱钥匙。成功逃脱者获得**2亿日元**奖金，但剩余每名囚犯将增加**4亿日元**债务。
  - **追放(放逐)投票**：每晚进行匿名投票，若**7人以上**投票支持放逐某玩家，该玩家被驱逐出游戏。被放逐者无法通关，且债务增加**1亿日元**。
  - **撕裂友情的机制**：
    - 多米诺骨牌需要全员长时间高度协作才能完成，任何一个人的破坏都能前功尽弃——内建了极端的脆弱性。
    - 逃脱机制让每个人心中都有"抛弃全员独自获利"的诱惑。
    - 放逐投票让猜疑制度化——每晚都有人可能被"朋友"投出局。
    - 田上源丈(Genjo Tagami)作为管理者/看守，是"规则至上主义者"，增加了权力不对称。
  - **通关奖励**：通关者每人获得**1亿日元**。
- **胜负条件**：全员完成多米诺或服完刑期 = 每人1亿日元；逃脱 = 逃者得2亿但全员+4亿债务；被放逐 = +1亿债务且出局
- **信息结构**：不完全信息（匿名投票、逃脱钥匙位置未知）
- **互动模式**：合作-背叛混合 + 投票放逐
- **所需能力标签**：团队协作、信任管理、投票策略、风险评估、联盟构建
- **AI 适配笔记**：极度适合 AI 移植。"集体劳动 + 逃脱诱惑 + 投票放逐"是一个三层嵌套的博弈结构，非常优秀。多米诺可抽象为"共同建造进度条"（每人每回合贡献或破坏），逃脱可设为"每回合有X%概率发现钥匙"，放逐投票直接可用。12人规模适合多 AI agent 场景。
