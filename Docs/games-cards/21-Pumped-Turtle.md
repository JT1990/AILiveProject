# 抽乌龟（抽鬼牌） / Pumped-Turtle / Old Maid

- **来源**: 纸牌
- **出处**: 传统游戏（全球广泛流行的经典纸牌游戏）
- **玩家人数**: 2-6 人
- **游戏时长**: 约 10-20 分钟
- **核心机制**: 随机抽牌配对消除，最终持有鬼牌者落败
- **规则摘要**: 使用一副53张牌（标准52张加1张鬼牌/Joker，或抽去一张Q使某个花色的Q无法配对）。开局将所有牌均匀分发给玩家，玩家先从手中找出所有成对的牌（相同点数的两张）打出消除。然后从持牌最多的玩家开始，轮流从右手边（或下家）的玩家手中随机抽取一张牌。如果抽到的牌能与手中某张配对，立即打出消除。如此循环直到所有配对的牌都被消除，最终手中剩下那张无法配对的鬼牌的玩家为输家（即"乌龟"）。
- **关键策略**: 表面上是纯运气游戏，但存在微妙的心理博弈：持有鬼牌的玩家会通过手牌的排列方式或面部表情（原版游戏中）诱导下家抽走鬼牌。反过来，抽牌者会试图从对方的行为中推断鬼牌的位置。手牌数量的变化也提供了信息——如果某玩家的牌减少得特别慢，可能暗示其持有鬼牌（不断被传来又传走）。
- **AI适配评估**:
  - 可行性: 中
  - 所需能力: [欺骗/心理建模/推理]
  - 改造建议: 原版游戏策略深度较浅，需要改造以适合AI对抗。核心改造方向：（1）AI抽牌时不是完全随机，而是需要选择从对手手中的哪个"位置"抽牌，对手则可以调整手牌排列来误导；（2）增加"言语环节"——持牌者可以发表声明（"我没有鬼牌""你应该抽最左边的"等），引入欺骗与反欺骗的语言博弈；（3）多轮积分制，输家扣分，增加长期策略维度。这样改造后可以测试AI的社交欺骗能力。
