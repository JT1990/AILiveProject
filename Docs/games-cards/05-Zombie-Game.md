# Zombie Game (僵尸游戏)

- **所属节目**：Genius Game (UK) S1E2
- **游戏阶段**：Main Match
- **玩家人数**：10 人（2 名初始僵尸 + 8 名人类）
- **核心机制**：隐藏身份 / 传染扩散 / 信任博弈
- **规则摘要**：
  **初始设定**：随机选出 2 名选手为"僵尸"。僵尸知道自己的身份，但**不知道另一名僵尸是谁**。

  **游戏时长**：3 轮，每轮 30 分钟。

  **触碰机制**：选手可以与其他选手"触碰"（双方将手放在一个灯上确认）。
  - **人类 + 人类** 触碰：双方各得 **1 分**
  - **僵尸 + 人类** 触碰：人类被感染，**变成僵尸**
  - **僵尸 + 僵尸** 触碰：无事发生
  - 每轮中，两人之间**只能触碰一次**
  - 每轮中，若某选手**未与任何人触碰**，自动变成僵尸

  **解药（Antidote）**：
  - 每位选手开局获得 **1 剂解药**
  - 被僵尸触碰后 **10 分钟内**使用解药可治愈
  - 额外解药可用 **5 颗 Garnet** 购买

  **胜负条件**：
  - **僵尸胜利**：若所有人类被感染，2 名初始僵尸各获 Token of Life + 3 颗 Garnet，并指定 Death Match 候选人
  - **人类胜利**：若有人类存活，得分最高的人类获胜（获 1 颗 Garnet/分）；得分最低的人类成为 Death Match 候选人

- **信息结构**：隐藏身份 / 不完全信息（僵尸身份保密，感染事件不公布）
- **互动模式**：阵营对抗（僵尸 vs 人类）+ 合作-背叛混合（人类之间需触碰得分但有被感染风险）
- **所需能力标签**：心理博弈、社交推理、风险评估、联盟构建、时机把握
- **AI 适配笔记**：
  非常适合移植。核心为传染扩散模型 + 隐藏身份推理。AI agent 需要：(1) 推测谁是僵尸，(2) 平衡得分需求与感染风险，(3) 决定解药使用时机。可建模为贝叶斯信念更新系统。"不触碰则自动感染"机制增加了博弈深度。多 agent 环境下可研究信任网络演化。
- **韩版对比**：直接翻拍韩版 S1E4 Zombie Game，规则基本一致。韩版为第 4 集，英版提前至第 2 集。
