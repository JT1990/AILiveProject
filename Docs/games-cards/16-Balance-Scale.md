# Balance Scale / Beauty Contest / 天秤 /美人投票

- **所属作品**：漫画 Side Story / Netflix S2E4-5
- **游戏阶段**：人头牌(Face Card)游戏
- **牌面与类型**：♦K（智力型，难度13/最高）
- **玩家人数**：5人（Netflix版：Chishiya + 4人 vs King of Diamonds / Kuzuryu）
- **核心机制**：迭代削除、p-Beauty Contest（凯恩斯选美博弈）
- **规则摘要**：游戏场地为最高法院。每轮所有玩家选择0到100之间的一个整数，计算所有人选择数字的平均值并乘以0.8——最接近这个结果的玩家赢得本轮。其他所有输家扣1分。累计扣至-10分的玩家死亡（硫酸池/化学雨执行）。最终唯一存活者通关。**递进规则（随玩家淘汰逐步追加）**：(1) 淘汰1人后：如果两名或以上玩家选择相同数字，该数字作废（即使最接近也扣分）；(2) 淘汰2人后：如果有人选中精确正确数字，其他玩家各扣2分（而非1分）；(3) 淘汰3人后：如果一人选0，另一人可以选100获胜。**博弈论分析**：由于平均值乘以0.8，最高合理选择为80；但如果所有人都不选超过80，最高合理值变为64；如此迭代推理最终收敛到0。这就是经典的p-Beauty Contest / Keynesian Beauty Contest。
- **胜负条件**：通关——成为最后存活者；死亡——累计扣至-10分（被硫酸/化学雨执行）
- **信息结构**：不完全信息（不知道其他人的选择，但结果公开可供学习）
- **互动模式**：纯对抗（多人自由竞争，只有1人存活）
- **所需能力标签**：博弈论、数学计算、心理建模（模拟他人思维层次）、策略适应、逻辑推理
- **AI 适配笔记**：**AI博弈研究的顶级素材**。p-Beauty Contest是实验经济学和博弈论的经典范式。核心在于理性层次推理——一阶理性选80，二阶选64，无穷阶选0。但如果其他人不是完全理性的呢？AI需要建模对手的理性层次（level-k reasoning / cognitive hierarchy）。递进规则进一步增加了策略复杂度。可以完美数字化，无需任何物理组件。极适合研究有限理性、学习动态、以及认知层次理论。
