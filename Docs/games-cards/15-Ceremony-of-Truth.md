# Ceremony of Truth (真相仪式)

- **所属节目**：The Traitors UK S3E6
- **游戏阶段**：Mission
- **玩家人数**：全体存活选手
- **核心机制**：**匿名投票 / 社交博弈 / 淘汰机制**
- **规则摘要**：所有人开始时持有 Shield。选手蒙眼后配对，每对需选出一名"不配持有 Shield"的人。被选中者头上会被倒一桶水（公开揭示）。被淋水者可以猜是谁投的——猜对则双方都失去 Shield。游戏进行到只剩 3 人持有 Shield 为止。
- **胜负条件**：保留 Shield（不被选中/猜对对方）
- **信息结构**：**不完全信息 / 匿名投票 + 推理**
- **互动模式**：**阵营对抗 / 社交博弈**
- **所需能力标签**：社交洞察力、心理博弈、推理、风险管理
- **AI 适配笔记**：**极高适配度**。核心是匿名投票 + 身份推断博弈。每轮：(1) 匿名选择淘汰对象；(2) 被淘汰者尝试识别投票者。这是一种"匿名惩罚+反推理"博弈。Traitor 可以利用匿名性针对性淘汰威胁者。可直接移植为纯策略游戏。
