Contraband Game（走私游戏）

| 字段         | 内容                                          |
| ------------ | --------------------------------------------- |
| **所属作品** | 漫画 Round III                                |
| **游戏阶段** | LGT Round 3                                   |
| **玩家人数** | 18 人（分为两队各 9 人）                      |
| **核心机制** | 团队走私/海关检查；信号博弈（Signaling Game） |

### 规则摘要

1. **分队**：18 名参赛者分为"北国"和"南国"两队，各 9 人。
2. **初始资金**：
   - 每人在"第三国"银行账户中持有 **1 亿日元**作为起始资金。
   - 每人在己方 ATM 中存有额外 **3 亿日元**可供提取使用。
3. **游戏长度**：共 **50 轮**（"game"）。每轮中，两队各派出一名走私者和一名海关检查员，然后角色互换，完成一组即为一"轮"。
4. **走私者规则**：
   - 走私者使用银行卡从**对方国家**的 ATM 中提取资金（注意：ATM 位于敌国）。
   - 每次最多携带 **1 亿日元**通过海关（可选择携带 0 至 1 亿）。
   - 资金放入手提箱，海关看不到金额。
5. **海关检查规则**：
   - 海关室隔音，其他队员无法听到走私者与检查员的对话。
   - 在海关室中最长停留 **10 分钟**。
   - 检查员有两个选择：
     - **"Pass"（通过）**：如箱内确实有钱，走私者成功将资金存入第三国账户；如箱内无钱，无事发生。
     - **"Doubt"（质疑）+ 金额**：检查员宣称箱内有钱并报出金额。
6. **Doubt 的三种结果**：
   - **正确质疑**（报出金额 ≥ 箱内实际金额）：海关没收箱内全部资金归己方。
   - **低估质疑**（报出金额 < 箱内实际金额）：走私者保留箱内全部资金，且获得额外赔偿金（indemnity）。
   - **错误质疑**（箱内为空）：走私者所在国获得赔偿金 = 检查员报出金额的 **一半**。
7. **终局清算**：50 轮结束后，各国 ATM 中**剩余的全部资金**归对方国家所有（全队均分）。个人收益 = 成功走私金额 + 获得的赔偿金 + 成功没收的走私资金 + 对方 ATM 剩余资金均分 + 第三国初始 1 亿。

**规则漏洞 / 可利用的规则**：

- **ATM 在对方国家**：这意味着走私者是从敌方 ATM 取钱再运回来——敌方可以监视 ATM 取款情况（取了多少、取没取）来推断走私金额。
- **海关室隔音**：走私者和检查员可在海关室内进行任何私下交易（包括合谋、贿赂等），外部队友无法监督。
- **赔偿金机制鼓励"空箱诈骗"**：反复空箱出发，诱使检查员 Doubt，可持续获得赔偿金。
- **终局 ATM 清算规则**：鼓励尽早取光己方 ATM 中的资金（否则归对方）。但这也意味着被走私走的总额上限是确定的。
- **个人 vs 团队矛盾**：虽然是团队对战，但最终结算是按个人收益计算的——这为内部出卖创造了空间。
