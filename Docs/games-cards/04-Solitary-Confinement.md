# Solitary Confinement / 独房 (禁闭)

- **所属作品**：漫画 / Netflix S2E3-4
- **游戏阶段**：人头牌(Face Card)游戏
- **牌面与类型**：♥J（心理型，难度11）
- **玩家人数**：20人（19名玩家 + Jack of Hearts 本人混入其中）
- **核心机制**：隐藏身份 + 信息依赖 + 信任网络
- **规则摘要**：游戏场地为帝王监狱。所有玩家佩戴爆炸项圈，项圈背面显示一个扑克花色符号（♠♥♦♣），但本人无法看到自己的符号。**核心规则**：每轮结束前（每轮约1小时），玩家必须回到各自牢房并说出自己项圈背面的花色符号。答对存活，答错或不回答则项圈爆炸。每轮结束后，所有人的符号随机改变。**信息限制**：玩家可以看到其他人的符号，但看不到自己的。场内移除了所有反光面——厨房刀具全为陶瓷，水龙头流出番茄汁而非水，无镜子。任何使用反光物品偷看自己符号的行为直接判定死亡。场内储备了足够一年的食物。游戏期间不消耗签证天数。**隐藏机制**：Jack of Hearts 混在19名玩家中，身份未知。如果Jack被杀，所有其他存活玩家自动通关。Jack可以对其他人谎报符号来制造信任危机。
- **胜负条件**：通关——杀死Jack of Hearts（其他所有人自动通关），或持续每轮答对直到游戏自然结束；死亡——答错自己的符号、不回答、或使用反光物品
- **信息结构**：隐藏身份 + 不完全信息（自己的符号依赖他人告知，但无法验证他人是否说谎）
- **互动模式**：合作-背叛混合（需要他人诚实告知自己的符号，但Jack会利用谎言制造混乱导致他人死亡）
- **所需能力标签**：心理博弈、信任管理、欺骗识别、联盟构建、逻辑推理、观察力
- **AI 适配笔记**：**极其优秀的AI博弈设计**。完美对应经典的信息博弈+隐藏叛徒模型。可以直接数字化：每轮每个AI看到除自己外所有人的「标记」，需要基于他人的报告猜测自己的标记。叛徒AI需要决定何时说谎、对谁说谎。信任网络的建立和崩溃是核心。类似于《狼人杀》但有更严格的信息结构。适合研究：信誉系统、信任传播、逆向推理（如果A告诉B的符号与C告诉B的不同，谁在说谎？）。
