# Minority Rule（少数决）

| 字段         | 内容                                    |
| ------------ | --------------------------------------- |
| **所属作品** | 漫画 Round II / 日剧 Season 1 第 4-6 集 |
| **游戏阶段** | LGT Round 2                             |
| **玩家人数** | 22 人                                   |
| **核心机制** | 多数淘汰投票；联盟分裂控制              |

### 规则摘要

1. **场地与道具**：在一栋豪华别墅中进行。每位玩家获发编号铭牌，铭牌上镶嵌一颗价值 **1 亿日元的粉色钻石**，作为本轮赌注。
2. **出题**：每轮由庄家（Leronira）从箱中随机抽取一个号码，该号码对应的玩家负责提出一个 **Yes/No 问题**（问题内容不限，不要求事实正确性）。
3. **投票**：每位玩家持有两张选票（YES 票和 NO 票，均印有该玩家编号）。投票时限为 **6 小时**。必须且只能投出一张选票，否则取消资格。
4. **计票与淘汰**：票数较多的一方为"多数派"，**全部淘汰**；票数较少的一方为"少数派"，**全部晋级**。被淘汰者须离开别墅并交出铭牌（含 1 亿日元钻石）。
5. **平票处理**：若 Yes 与 No 票数相同，重新抽号出题、重新投票。
6. **终局**：重复投票淘汰，直到剩余 **1 或 2 人**时游戏结束（此时无法再构成少数派）。存活者瓜分所有淘汰者的钻石。

**规则漏洞 / 可利用的规则**：

- **偶数联盟策略**：若能组建一个偶数人数的联盟，联盟内部平分投 Yes 和 No，则无论非联盟成员如何投票，联盟至少有一半人处于少数派存活。这是秋山的核心策略。
- 投票是**秘密**的——但选票上印有编号，计票后可追溯谁投了什么，因此"背叛联盟"有被发现的风险。
- 出题者可通过精心设计问题来诱导特定投票倾向。
- 6 小时投票期允许大量场外交涉和拉票。

| 字段             | 内容                                                                                                                                                                                                                                                        |

| **胜负条件**     | 每轮多数派全部淘汰并失去 1 亿日元钻石；最终存活的 1-2 人瓜分全部钻石为赢家。                                                                                                                                                                                |
| **信息结构**     | 投票为秘密投票，但计票后公开每张选票的编号（可追溯投票者）。玩家之间可自由交流和结盟，但无法验证承诺。                                                                                                                                                      |
| **互动模式**     | 多人联盟/分裂；承诺与背叛；6 小时谈判期。                                                                                                                                                                                                                   |
| **所需能力标签** | `联盟构建` `投票博弈` `概率计算` `信息控制` `背叛检测`                                                                                                                                                                                                      |
| **AI 适配笔记**  | 高度适合 AI——每轮决策空间仅为二元（Yes/No），但策略空间巨大。核心在于联盟组建与维持：AI 需要 (1) 估算联盟成员的可信度，(2) 决定联盟内部的投票分配，(3) 在偶数联盟策略中精确计算安全阈值。可建模为带通信阶段的重复少数决博弈。联盟协调需要自然语言谈判能力。 |
