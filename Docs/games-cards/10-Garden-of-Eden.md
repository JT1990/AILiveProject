# Garden of Eden（伊甸园）

| 字段         | 内容                                              |
| ------------ | ------------------------------------------------- |
| **所属作品** | 电影 Liar Game: The Final Stage（2010）           |
| **游戏阶段** | 日剧/电影版 Final Stage 决赛                      |
| **玩家人数** | 11 人                                             |
| **核心机制** | 三色苹果投票；公共品博弈（Public Goods Game）变体 |

### 规则摘要

1. **道具**：每轮每人选择一个苹果——**金色（Gold）**、**银色（Silver）**或**红色（Red）**——刻上自己的名字后投入收集槽。
2. **游戏结构**：每 **1 小时**一轮，共 **13 轮**。
3. **赔付矩阵**（核心规则）：
   - **全员红色**：所有人 **+1 亿日元**。（合作均衡）
   - **全员同一颜色（全金或全银）**：所有人 **-1 亿日元**。
   - **仅有金和银（无红）**：多数色方 **+1 亿**，少数色方 **-1 亿**。（若完全对半则需特殊处理）
   - **红色 + 金/银混合（红方人数 ≥ 2）**：红色方全体 **-1 亿**；金/银方全体 **+1 亿**。
   - **仅 1 人红色**：该红色玩家 **-10 亿日元**（身份被公开）；其余所有人 **+1 亿**。
   - **仅 1 人金/银（其余全红）**：该金/银玩家 **+2 亿日元**；其余全体 **-1 亿**。
4. **淘汰线**：累计负债超过 **5 亿日元**的玩家被淘汰。
5. **限制**：玩家之间**不得分享奖金**（禁止赛后转账）。

**规则漏洞 / 可利用的规则**：

- **红色是"合作选项"但极度脆弱**：只要有一个人背叛投金/银，所有投红的人都亏损。尤其是"仅 1 人红色"的惩罚高达 -10 亿。
- **经典公共品困境**：全员投红是帕累托最优（所有人都赚），但每个人都有激励偏离——投金/银可以保证不亏（多数色方赢），而投红冒着被背叛的风险。
- **"1 人红色"陷阱**：如果其他人都知道你要投红，他们可以集体转投金/银，使你成为唯一的红色，损失 10 亿。
- **13 轮的学习效应**：早期轮次的投票结果为后续策略提供信息。
- **LGT 事务局的真正目的**（剧情揭示）：整个 Final Stage 背后是富豪们在赌"是否会出现一轮全员投红"——如果出现，庄家（LGT）巨额亏损。
