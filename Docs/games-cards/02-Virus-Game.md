# The Virus Game / 바이러스 게임 (病毒游戏)

- **所属节目**：The Devil's Plan S1E01–E02
- **游戏阶段**：Main Match（第 1 天）
- **玩家人数**：12 人；分为恐怖分子阵营（2 人）与市民阵营（10 人），市民中含特殊角色
- **核心机制**：隐藏身份、社会推理、阵营对抗
- **规则摘要**：
  类似"狼人杀"的隐藏身份游戏。12 名玩家被编号入座，游戏分为 30 分钟一轮的多轮制。

  **角色分配**：
  - **恐怖分子**（2 人）：目标是传播病毒。每轮可选择感染一名玩家，也可使用子弹射杀一名玩家或拯救一名被感染者。
  - **普通市民**（5 人）：无特殊能力，需推理并投票找出恐怖分子。
  - **研究员**（2 人）：寻找拥有抗体的市民以开发解药。每轮可选择一名玩家进行抗体检测。
  - **抗体持有者**（1 人）：身份保密，研究员需找到此人以研发解药。
  - **警官**（1 人）：每轮可射杀一名玩家（希望击中恐怖分子）。越早击杀恐怖分子获得越多 Piece。
  - **狂信者**（1 人）：表面为市民，实际帮助恐怖分子。
  - **记者**（1 人）：目标是在存活状态下揭露所有人的身份，成功则获得额外 Piece。

  **病毒传播机制**：若编号 5 被感染，则下一轮病毒向相邻编号（4 和 6）扩散。被感染两轮后玩家"死亡"出局。

  **计分**：市民方胜利时每人获得 1 Piece，存活的市民额外获得 1 Piece。研究员成功开发解药可获额外 Piece。

- **胜负条件**：
  - 市民方胜利：击杀两名恐怖分子，或研究员成功开发解药（找到抗体持有者）。
  - 恐怖分子方胜利：至少一名恐怖分子存活且抗体持有者也存活（使解药无法生效）。
- **信息结构**：隐藏身份 / 私有信号（每个角色拥有不同私有信息）
- **互动模式**：阵营对抗（恐怖分子 vs 市民，狂信者为内鬼）
- **所需能力标签**：心理博弈、逻辑推理、语言说服、信息收集、联盟管理、欺骗与反欺骗
- **AI 适配笔记**：非常适合 AI 智能体。可直接建模为不完全信息博弈。核心挑战在于：(1) 自然语言交流中的谎言检测，(2) 贝叶斯推理更新角色概率，(3) 多角色异构行动空间。移植时需定义清晰的通信协议和行动 API。
