# Food Chain (먹이사슬)

- **所属节目**：The Genius S2E1
- **游戏阶段**：Main Match
- **玩家人数**：13人
- **核心机制**：隐藏身份、角色扮演、空间移动、生存策略
- **规则摘要**：每位玩家秘密获得一个动物身份，共13种：4种捕食者（狮子、鳄鱼、老鹰、鬣狗）和9种猎物，各有不同能力。游戏4轮，每轮10分钟，有4个栖息地（森林、草原、河流、天空）。捕食者通过贴标签攻击猎物；高级捕食者可吃低级动物。各捕食者有饥饿限制——狮子每轮必须进食，鳄鱼和老鹰可跳过一轮，鬣狗可跳过两轮。特殊角色包括：蛇（如果8+动物死亡则反杀攻击者）、变色龙（伪装为其他动物）、牙签鸟（鳄鱼存活则自己获胜）、老鼠（狮子存活则自己获胜）、乌鸦（预测另一个赢家则获胜）、鹿/兔/鸭/水獭（同族全部在同一栖息地时获得免疫）。赢家共同选出淘汰候选人。
- **胜负条件**：满足各自角色的胜利条件；赢家们集体选出Death Match候选人
- **信息结构**：隐藏身份 + 私有信号（各角色有独特信息和能力）
- **互动模式**：阵营对抗 + 合作-背叛混合（捕食者vs猎物，但各角色有不同胜利条件）
- **所需能力标签**：推理判断、社交欺骗、空间策略、角色扮演、联盟管理
- **AI 适配笔记**：复杂的多角色隐藏身份游戏。AI需要根据行为推理其他玩家的角色身份。多个不同的胜利条件创造了复杂的激励结构。可以数字化但规则复杂度高，适合作为多Agent系统测试平台。
