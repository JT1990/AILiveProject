# Scamming Horse Race (사기 경마)

- **所属节目**：The Genius S1E5
- **游戏阶段**：Main Match
- **玩家人数**：9人
- **核心机制**：信息差、推理、拍卖/下注、谈判
- **规则摘要**：8匹马进行一场预先确定结果的赛马。每名玩家获得一条不同的线索（关于比赛结果的部分信息）；另有3条额外线索可以花3颗宝石购买。每人获得20枚下注筹码。比赛共12轮下注回合，每轮可对尚未接近终点3格以内的马匹下注，每轮最多下注3枚筹码。第一名和第二名到达终点的马匹为赢家，押中的玩家获得赔付。游戏结束后，赢得最多筹码的玩家获得2个生命代币；赢得最少的成为淘汰候选人。每10枚筹码可兑换1颗宝石。
- **胜负条件**：筹码最多者胜出；筹码最少者进入Death Match
- **信息结构**：私有信号（每人持有不同线索，信息不对称）
- **互动模式**：合作-背叛混合（可以交换线索信息，但也可能欺骗）
- **所需能力标签**：逻辑推理、信息整合、谈判说服、风险评估、数学计算
- **AI 适配笔记**：经典的信息聚合博弈。AI可以高效地进行贝叶斯推理整合多条线索。核心挑战是如何在不完全信息下做出最优下注决策，以及是否信任他人分享的信息。非常适合AI实现。
