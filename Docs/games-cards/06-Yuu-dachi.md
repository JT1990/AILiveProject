# 友断ちゲーム (Yuu-dachi Game / 断友游戏 / 绝交游戏)

- **所属作品**：漫画第19-26卷（最终篇）
- **游戏阶段**：大人のトモダチゲーム 第3回（最终游戏）
- **玩家人数**：多人（在山间小屋中共同生活）
- **核心机制**：密码控制 + 任务执行 + 身份揭露 + 长期共处博弈
- **规则摘要**：
  - 场景设定在偏远**山间小屋**中，为期**2周（14天）**。通关条件表面上很简单：所有人在小屋中生活2周。
  - **密码(パスワード)系统**：每名玩家被分配一个秘密密码。知道他人密码的人可以对其行使**"完全控制权"**——实际上是向运营方报告密码来**使该玩家失效/淘汰**。
  - **每日任务**：运营方Manabu通过智能手机向每名玩家单独发送任务。任务具有以下特征：
    - 任务内容**互相矛盾**或**道德上不可接受**（迫使玩家陷入道德困境）。
    - 任务规则对每个玩家**单独说明**（信息不对称——你不知道别人收到了什么任务）。
    - 不完成任务会导致**淘汰**或**债务增加**。
  - **BOSS识别**：玩家的终极目标之一是找出隐藏在参赛者中的**"BOSS"**——Tomodachi Game 的幕后操控者。
  - **最终奖金**：最后存活的队员获得约**45亿日元**奖金。
  - **撕裂友情的机制**：
    - 密码系统让"了解朋友"变成了武器——知道某人的秘密就能消灭他。这是对"友情=互知"的终极讽刺。
    - 互斥任务设计让合作在逻辑上不可能——你的任务可能要求你背叛完成别人任务所需的条件。
    - 14天长期共处让心理压力持续累积，不像短期游戏可以"忍过去"。
    - 信息隔离(每人单独接收规则)让猜疑无限放大——你甚至不知道游戏到底是什么。
    - **主题升华**：游戏名"友断ち"(断友)直接表明目的——在极端压力下证明"所有人最终都是孤独的"，友情不过是幻觉。
- **胜负条件**：在小屋中存活2周 + 揭露BOSS = 终极通关；被密码淘汰/任务失败 = 出局 + 债务累积
- **信息结构**：极度不完全信息（单独规则、隐藏密码、隐藏身份、互斥任务）
- **互动模式**：合作-背叛混合 → 逐渐演变为纯对抗
- **所需能力标签**：长期策略、心理博弈、信息管理、身份推理、任务优先级判断、联盟维护与瓦解
- **AI 适配笔记**：**这是全系列最适合 AI 真人秀的游戏。** "密码=控制权"机制直接可用：每个 AI agent 有一个秘密token，收集他人token可消灭对方。每日互斥任务系统完美适配每轮下发不同目标的 AI 真人秀结构。14天长期共处可压缩为14轮游戏回合。BOSS身份隐藏增加了社会推理层。核心价值在于它展示了"长期博弈如何系统性地摧毁信任"——这正是 AI 真人秀最有戏剧性的叙事引擎。
