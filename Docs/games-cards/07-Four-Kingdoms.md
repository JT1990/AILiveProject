# The Records of the Four Kingdoms（四国志）

| 字段         | 内容                                                      |
| ------------ | --------------------------------------------------------- |
| **所属作品** | 漫画 Round V（最终决赛）                                  |
| **游戏阶段** | LGT Round 5——决赛                                         |
| **玩家人数** | 16 人（4 队 × 4 人），由 Artier（LGT 事务局 CEO）亲自主持 |
| **核心机制** | 多方同时行动博弈；攻守 LP 消耗                            |

### 规则摘要

1. **队伍构成**：4 支"王国"，每队 4 人。队伍由前置游戏（Collective Ghostleg + Human Auction）决定。
2. **生命值**：每个王国起始 **100 LP**（Live Points）。
3. **回合行动**：每回合，每个王国**同时**秘密选择行动，最多执行 **3 个动作**（也可选择 0 个）。可选动作为：
   - **攻击**（Attack）某个指定王国（消耗 1 LP）
   - **防御**（Defend）来自某个指定王国的攻击（消耗 1 LP）
4. **行动结算**（同时揭示后结算）：
   - **发动攻击 + 对方未防御** → 攻击方 -1 LP，防御方 **-3 LP**
   - **发动攻击 + 对方防御** → 双方各 -1 LP（攻防抵消）
   - **未发动攻击 + 对方防御** → 防御方白费 -1 LP，攻击方无损耗
   - **双方均无动作** → 无消耗
5. **淘汰**：LP 降至 0 的王国被淘汰。游戏持续到只剩 **1 个王国**。
6. **只有一个赢家**：四个王国中三个必须被消灭。

**规则漏洞 / 可利用的规则**：

- **第三方渔利**：若 A 攻击 B 且 B 未防御，B 损失 3 LP——但 C 和 D 不花任何代价也享受了 B 被削弱的好处。攻击者独自承担成本（-1 LP），其他所有人分享收益。这导致"搭便车"问题——没人愿意率先攻击。
- **联盟的不稳定性**：两国联盟可以互相免去防御成本（互不攻击），从而集中 3 个动作全部用于攻击第三方或防御第三方。但最终只能有一个赢家，联盟必然破裂。
- **防御的信息价值**：如果你预判没有人会攻击你，防御就是白费 LP。但如果误判，不防御的代价是 3 LP——是防御成本的 3 倍。这是经典的"预判博弈"。
- **最优混合策略**：数学上每个王国的均衡策略是攻击概率 2/3、防御概率 2/3，每回合期望损失约 2/3 LP。

| 字段             | 内容                                                                                                                                                                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **胜负条件**     | 最后存活的王国获胜；其余三国所有成员败北。                                                                                                                                                                                                                                                    |
| **信息结构**     | 每回合行动同时秘密选择，揭示后结算。LP 公开。历史行动可追溯。                                                                                                                                                                                                                                 |
| **互动模式**     | 4 方同时行动博弈；联盟谈判在回合间进行；联盟形成与破裂是核心。                                                                                                                                                                                                                                |
| **所需能力标签** | `多方博弈论` `混合策略均衡` `联盟谈判` `背叛时机` `资源管理`                                                                                                                                                                                                                                  |
| **AI 适配笔记**  | 非常适合 AI 形式化建模。可直接建模为 4 方同时移动博弈（Simultaneous Move Game），每方每回合有 64 种可能行动组合（攻/守 × 3 个对手，各自选择 0-3 个动作的子集）。纳什均衡可通过线性规划求解。关键难点在于联盟阶段的自然语言谈判和信号解读——AI 需要评估联盟承诺的可信度，并选择最优的背叛时机。 |
