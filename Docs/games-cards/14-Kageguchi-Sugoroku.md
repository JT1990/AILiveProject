# 陰口スゴロク (Kageguchi Sugoroku / 恶口飞行棋 / 阴口双六)

- **所属作品**：漫画第4-9话（第2-3卷） / 动画 E3-E6
- **游戏阶段**：第2回游戏
- **玩家人数**：5人（C组全员）
- **核心机制**：信息暴露博弈、社会性惩罚、囚徒困境变体
- **规则摘要**：
  - 棋盘游戏形式，60格跑道。玩家轮流投入"陰口ペーパー(恶口纸条)"来决定前进步数。
  - 每回合所有玩家进入**独立密室**，有3分钟时间在纸条上写下关于其他玩家的"恶口"（可以是秘密、缺点、丑闻等侮辱性内容）。每人可同时诽谤多个人，也可以交白卷。
  - 纸条被匿名提交给运营方后，由隐藏的**观众(神明审判员)**投票评判，选出"最不可饶恕"的内容。被投票为最恶劣的玩家获得最多前进步数。
  - **撕裂友情的机制**：
    - 恶口越劲爆，揭露的秘密越致命，玩家前进越多——游戏直接**激励出卖朋友**。
    - **虚假恶口惩罚**：如果写了假的恶口（不实内容），该玩家自动被罚至第一名位置（实为惩罚位），暴露了说谎者的身份。
    - **全员白卷**：若所有人都交白卷，则所有玩家一起前进（合作路线）。但只要有一人写了恶口，合作就崩溃。
    - **"第一名惩罚"**：最先到达终点的人**不是胜者而是失败者**——该玩家将被强制进入下一个更危险的游戏，且无法获得减免。其余玩家借金各减100万日元并可回家。这个规则的反直觉设计让玩家陷入两难：要前进就得出卖朋友，但走得太快反而自己受罚。
  - **关键剧情**：此游戏揭露了天智暗中跟踪志法的事实，以及天智是组织全员参加游戏的始作俑者。
- **胜负条件**：最先到达终点者 = 输家（强制进入第3游戏）；其他人 = 借金减100万 + 可以回家
- **信息结构**：不完全信息（恶口匿名提交，但内容会被公开）+ 隐藏观众评判
- **互动模式**：合作-背叛混合（全员白卷可合作，但背叛激励极强）
- **所需能力标签**：心理博弈、语言说服、信息操控、风险评估、社会压力管理
- **AI 适配笔记**：高度适合 AI 移植。"匿名揭秘 + 观众投票"机制可直接数字化。核心博弈——"合作交白卷 vs 背叛揭秘"——是经典囚徒困境变体。"第一名惩罚"的反直觉设计值得保留，可增设"连续揭秘奖励"或"累计信誉系统"增加深度。需为 AI 设计"秘密池"作为揭露素材来源。
