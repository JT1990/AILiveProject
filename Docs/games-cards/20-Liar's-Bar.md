# 骗子酒馆 / Liar's Bar

- **来源**: 酒桌游戏 / 电子桌游
- **出处**: 近年热门独立游戏（融合大话骰与俄罗斯轮盘机制）
- **玩家人数**: 2-4 人
- **游戏时长**: 约 10-20 分钟
- **核心机制**: 欺骗与质疑——打出手牌并声称牌型，允许说谎；下家选择相信或质疑，判错者接受俄罗斯轮盘惩罚
- **规则摘要**: 每位玩家获得一手牌。每回合玩家打出最多3张牌并公开声称自己打出的牌型（允许并鼓励掺杂假牌进行欺骗）。下家必须选择：相信并继续出牌加码，或质疑并翻开验证。若质疑成功（对方确实说谎），说谎者须接受一次"俄罗斯轮盘"惩罚（左轮手枪开枪，有概率"死亡"出局）；若质疑失败（对方说的是真话），质疑者自己承受惩罚。存活到最后的玩家获胜。每次惩罚不一定致命，但轮盘概率逐渐累积。
- **关键策略**: 核心在于欺骗频率与可信度的平衡——全说真话会被轻易加码碾压，频繁说谎则被质疑的风险激增。读取对手的说谎模式、控制轮盘风险累积节奏、以及"半真半假"的混合策略是高阶玩法。
- **AI适配评估**:
  - 可行性: 高
  - 所需能力: [欺骗/推理/概率计算/风险管理/心理博弈]
  - 改造建议: 天然适配纯文本环境。手牌分配、出牌声明、质疑决策均可文本交互完成，俄罗斯轮盘由系统概率模拟。这是测试AI欺骗与反欺骗能力的顶级场景——AI需学习构建可信的谎言、追踪对手的诚实度历史、评估质疑的期望收益。可增加"表情/语气"文本线索层让AI模拟微表情泄露。
