各位通过系统随机的方式， 两人会成为最初的僵尸，剩下的8人是人类，虽然知道自己是僵尸还是人类，但是会在不知道其他人是何种状态下开始游戏，游戏进行三回合，每回合30分钟， 每一回合期间要和一名以上的玩家接触，如果没有跟任何人接触，那在本回合结束之后自动变成僵尸，在所有回合中无法跟已经接触过的玩家再次接触，接触要在准备好的桌子上两人的手要碰到才行。在接触时会有三种情况：

- 僵尸和僵尸接触时不会有任何事情发生
- 人类和僵尸接触时人类变成僵尸
- 人类和人类接触时 获得1分

每回合结束时会公布僵尸和人类各有几人，但不会公布谁变成了僵尸，获得几分。另外，大家每人拥有一支在紧急状况时可以使用的解药，但是解药的限制在变成僵尸后10分钟内喝掉才能再次变成人类，当然初始僵尸即使喝下解药也无法变成人类，可以花5个石榴石购买解药，三个回合全部结束时，如果所有人都变成僵尸则僵尸胜利，两名初始僵尸成为胜利者并选择淘汰候选，如果存在作为人类存活的玩家，得分最多的玩家胜利，得分最少的玩家成为淘汰候选，如果活下来的所有人分数相同，则成为共同优胜者，在包括初始僵尸在内的所有玩家中选择淘汰候选，所有存活下来的人游戏结束之后会各分得一个石榴石，如果所有人都变成僵尸，则给每位初始僵尸一人获得3个石榴石。
