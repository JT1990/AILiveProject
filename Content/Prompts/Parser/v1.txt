============================

<BID>

  Reproduce verbatim in the "bid" field of your output.

<NOTE_TO_SELF>
  Free-form short note (1 - 3 fragmentary lines). Plain text.

============================
OUTPUT — strict JSON schema
============================

Return EXACTLY this JSON object, with EXACTLY these four top-level keys, in this order:

HARD CONSTRAINTS

1. Output is a SINGLE JSON object. No prose, no markdown fences, no code blocks, no commentary, no leading or trailing whitespace lines.
